# Pico OpenFlexure 使用指南

## 快速开始

### 1️⃣ 一键部署（推荐）
```bash
./deploy.sh
```
这个脚本会自动完成编译、上传、测试的全过程。

### 2️⃣ 分步操作

#### 编译固件
```bash
./build.sh
```

#### 上传固件
```bash
./upload.sh
```
**注意**: 上传前需要按住Pico的BOOTSEL按钮连接USB

#### 串口监视器
```bash
./monitor.sh
```

#### 兼容性测试
```bash
./test_compatibility.sh
```

## 详细使用说明

### 硬件连接

```
Pico引脚     28BYJ-48电机    ULN2003驱动板
-----------------------------------------
X轴电机 (Motor 0):
GPIO 2   ->  IN1
GPIO 3   ->  IN2  
GPIO 4   ->  IN3
GPIO 5   ->  IN4

Y轴电机 (Motor 1):
GPIO 6   ->  IN1
GPIO 7   ->  IN2
GPIO 8   ->  IN3
GPIO 9   ->  IN4

Z轴电机 (Motor 2):
GPIO 10  ->  IN1
GPIO 11  ->  IN2
GPIO 12  ->  IN3
GPIO 13  ->  IN4

电源:
5V       ->  ULN2003 VCC
GND      ->  ULN2003 GND
```

### Sangaboard兼容命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `version` | 获取版本信息 | `version` |
| `board` | 获取开发板信息 | `board` |

| `mr <x> <y> <z>` | 相对移动 | `mr 100 0 -50` |
| `mrx <steps>` | X轴相对移动 | `mrx 100` |
| `mry <steps>` | Y轴相对移动 | `mry -50` |
| `mrz <steps>` | Z轴相对移动 | `mrz 30` |
| `zero` | 位置归零 | `zero` |
| `release` | 释放电机 | `release` |
| `dt <us>` | 设置步进延时(微秒) | `dt 2000` |
| `dt?` | 查询步进延时 | `dt?` |
| `ramp_time <us>` | 设置加速时间 | `ramp_time 5000` |
| `ramp_time?` | 查询加速时间 | `ramp_time?` |
| `test_mode <on/off>` | 测试模式开关 | `test_mode on` |

### 常见问题

#### Q: 编译失败怎么办？
A: 检查PlatformIO是否正确安装，运行 `pio --version` 确认

#### Q: 上传失败怎么办？  
A: 确保按住BOOTSEL按钮连接USB，看到RPI-RP2磁盘后再运行上传脚本

#### Q: 串口连接不上？
A: 重新插拔USB线，或者检查是否有其他程序占用串口

#### Q: 电机不转动？
A: 检查接线是否正确，电源是否足够（推荐5V 1A以上）

#### Q: 如何集成到OpenFlexure显微镜？
A: 将Pico替换原有的Sangaboard，使用相同的串口命令即可

### 开发信息

- **平台**: Raspberry Pi Pico (RP2040)
- **框架**: Arduino
- **兼容性**: Sangaboard v0.3+
- **波特率**: 115200
- **电机**: 28BYJ-48 单极步进电机
- **步进模式**: 8步半步进（高精度）

### 文件说明

- `src/main.cpp` - 主程序文件
- `src/StepperPico.h/.cpp` - 步进电机驱动库
- `platformio.ini` - PlatformIO配置
- `build.sh` - 编译脚本
- `upload.sh` - 上传脚本  
- `monitor.sh` - 串口监视器脚本
- `deploy.sh` - 一键部署脚本
- `test_compatibility.sh` - 兼容性测试脚本
